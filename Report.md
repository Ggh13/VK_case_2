# Отчет по проекту: Разработка гибридной поисковой RAG-системы

## Распределение обязанностей и вклад участников проекта

Архитектура системы поискового движка с поддержкой RAG была разделена на два крупных логических блока: модуль сбора/индексации данных и поисково-генеративный веб-сервис.

---

### Вадим — Разработка модуля парсинга и построения индексов

**Выполненные задачи:**
* **Сбор данных (Парсинг):** Реализовал модуль взаимодействия с arXiv API. Настроил безопасный сбор XML-ответов через `BeautifulSoup`, очистку сырого текста от мусорных символов и обработку специфических крайних случаев (обработка кросс-постинга категорий, защита скрипта от отсутствующих тегов).
* **Препроцессинг данных:** Реализовал детерминированную генерацию UUID-идентификаторов для стабильности базы данных, а также склейку метаданных для формирования поискового текстового корпуса.
* **Лексическое индексирование:** Настроил лингвистическую токенизацию текстов с помощью библиотеки `NLTK` и обучил статистическую поисковую матрицу **BM25Okapi**, сохранив индекс в бинарный формат для мгновенного импорта.
* **Семантическое индексирование:** Разработал пайплайн для работы с нейросетевыми эмбеддингами. Настроил обработку текстов моделью `BAAI/bge-small-en-v1.5`.
* **Векторная база данных:** Спроектировал локальное хранилище в **Qdrant**, настроил конфигурацию коллекции под косинусное сходство (Cosine Distance).

---

### Слава — Разработка поискового движка, ранжирования и RAG-пайплайна (Ranking & LLM)

**Выполненные задачи:**
* **Веб-инфраструктура:** Спроектировал и развернул веб-сервер на базе **FastAPI** и **Uvicorn**, настроил эндпоинты для гибридного поиска (`/search`) и генеративного ответа (`/ask`), а также роутинг статических файлов фронтенда.
* **Локализация запросов:** Реализовал слой динамического перевода пользовательских запросов с помощью `deep-translator` с валидацией кириллицы через регулярные выражения.
* **Гибридное ранжирование (RRF):** Разработал ядро поисковой системы — алгоритм **Reciprocal Rank Fusion (RRF)**. Реализовал математическое слияние независимых списков выдачи от BM25 и Qdrant, решив проблему разности шкал оценивания через приведение к ранговым бонусам.
* **Интеграция с LLM (RAG):** Разработал систему генерации ответов на основе контекста. Подключил API **Groq** для работы с высокоскоростной моделью **Llama 3.3 (70B)**.
* **Промпт-инжиниринг:** Спроектировал строгие системные инструкции (`RAG_SYSTEM_PROMPT`), минимизирующие галлюцинации нейросети, настроил сборку контекста с сохранением ссылок на первоисточники и форматирование итогового ответа на русском языке.
